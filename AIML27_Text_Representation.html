i Why Represent Text?

Machine Learning algorithms work on numbers, not raw text. To use ML on words, sentences, or documents, we must first convert language into numerical vectors. This conversion is called text representation or feature extraction.

Four Main Techniques Covered

1️⃣ Bag of Words / Count Vectorizer — counts word occurrences per document
2️⃣ One-Hot Encoding — each word becomes a unique binary vector
3️⃣ TF-IDF Encoding — weighs words by importance across the corpus
4️⃣ N-Gram Representation — captures sequences of N consecutive words

1 Bag of Words (BoW)

The simplest method: count how many times each vocabulary word appears in each document. Word order is ignored — we treat each document as a "bag" of words.

(unique words from all docs)"] V --> X["Count occurrences
per document"] X --> Y["📊 Document Vectors"] style V fill:#fef3c7 style Y fill:#d1fae5

⚠️ Limitations of BoW:
  • Ignores word order ("dog bites man" = "man bites dog")
  • Common words like "the" dominate counts but carry little meaning
  • Sparse, high-dimensional vectors

2 One-Hot Encoding

Each unique word in the vocabulary is represented by a vector that contains a single 1 and all other positions are 0. The position of the 1 identifies the word.

💡 In Python (sklearn): 
from sklearn.preprocessing import OneHotEncoder
encoder = OneHotEncoder()
encoder.fit_transform(words.reshape(-1, 1))
⚠️ Drawback: Vector size = vocabulary size. With 100,000 words, every encoding is a 100,000-dimensional sparse vector. Also, no semantic similarity is captured (cat & dog look as different as cat & the).

3 TF-IDF Encoding

TF-IDF = Term Frequency × Inverse Document Frequency. It rewards words that appear often in a document, but penalises words that appear in many documents (because those carry less unique information).

(Term Frequency)

(Inverse Doc Freq)
= rare words → high score"] --> R R --> N["L2 Normalize"] N --> V["📊 Final Vector"] style TF fill:#fef3c7 style IDF fill:#fef3c7 style V fill:#d1fae5

Step 4 — Compute IDF (sklearn formula, smooth)

$$ \text{IDF}(t) = \log\left(\frac{1 + N}{1 + DF(t)}\right) + 1 \quad\quad \text{where } N = 4 $$

Example — andrew (DF = 1)

$$ \text{IDF(andrew)} = \log\left(\frac{1+4}{1+1}\right) + 1 = \log(2.5) + 1 = 0.9163 + 1 = \mathbf{1.9163} $$

Example — dog (DF = 2)

$$ \text{IDF(dog)} = \log\left(\frac{1+4}{1+2}\right) + 1 = \log(1.667) + 1 = 0.5108 + 1 = \mathbf{1.5108} $$

Example — boy (DF = 3)

$$ \text{IDF(boy)} = \log\left(\frac{1+4}{1+3}\right) + 1 = \log(1.25) + 1 = 0.2231 + 1 = \mathbf{1.2231} $$

Step 6 — L2 Normalization

$$ \text{TF-IDF}_{\text{norm}}(t) = \frac{\text{TF-IDF}(t)}{\sqrt{\sum_{i} \text{TF-IDF}(i)^2}} $$

For D₁:

$$ \text{Norm} = \sqrt{1.22^2 + 1.5108^2} = \sqrt{1.4884 + 2.2825} = \sqrt{3.7709} \approx 1.94 $$
(approx 1.5 in the handwritten shorthand)

Final normalized values for D₁:

boy → 1.22 / 1.94 ≈ 0.628   |   dog → 1.51 / 1.94 ≈ 0.778
💡 Key Insight: Rare words (andrew, cat, ratna) get high TF-IDF scores; common words (boy) get lower scores. This makes the model focus on discriminative vocabulary.

4 N-Gram Representation

An N-gram is a contiguous sequence of N items from text. Unlike BoW, N-grams preserve some word order and local context.

Unigram (N=1)
Single words: "the", "boy"
Bigram (N=2)
Two-word pairs: "the boy", "boy and"
Trigram (N=3)
Three-word seq: "the boy and"

Example — Bigrams of "The boy and the cat"

Sliding window of size 2:

The boy and the cat
The boy and the cat
The boy and the cat
The boy and the cat

Resulting bigram vocabulary:

The boy boy and and the the cat

💡 Why N-grams matter: "not good" vs "good" mean opposite things. Bigrams capture this; unigrams (BoW) cannot.

🌐 Web Scraping

Web scraping is the process of automatically collecting data from websites. It's a key way to build text corpora for ML.

Common Data Sources

📄 CSV files — comma-separated tabular data
📊 Excel files — spreadsheets
🔌 APIs — structured endpoints (REST/GraphQL)
🧾 JSON data — nested key-value records

10-Step Web Scraping Workflow

  1. Choose website — pick the source you want to extract data from
  2. Send HTTP request — use libraries like requests (Python)
  3. Download HTML — receive the raw page content
  4. Parse HTML — use BeautifulSoup or lxml to navigate the DOM
  5. Extract required data — target specific tags, classes, IDs
  6. Clean the data — strip whitespace, fix encoding, handle missing values
  7. Store in DB — push to SQL, CSV, MongoDB, etc.
  8. Analyze data — exploratory data analysis (EDA)
  9. Feature extraction — apply BoW / TF-IDF / N-grams to text columns
  10. Apply algorithms — train ML models on the prepared features

Common HTML Tags for Scraping

<h1>...</h1> <span>...</span> <p class="rating">...</p> <table> <tr> <td> </table>
🐍 Python Snippet: 
import requests
from bs4 import BeautifulSoup

url = "https://example.com/product"
html = requests.get(url).text
soup = BeautifulSoup(html, "html.parser")

name  = soup.find("h1").text
price = soup.find("span", class_="price").text
rating = soup.find("p", class_="rating").text
⚠️ Always check: the site's robots.txt, Terms of Service, and rate-limit your requests. Use APIs whenever they exist.
